# Simple Login & Register App (Bootstrap CDN)

Proyek latihan pertama membuat antarmuka halaman autentikasi (Login dan Registrasi) yang responsif menggunakan **Bootstrap 5 CDN**.

## 🚀 Fitur Proyek
- Halaman Login (`index.html`) dengan form input email dan password.
- Halaman Registrasi (`register.html`) dengan tambahan input nama lengkap.
- Menggunakan komponen *Card*, *Form*, dan *Flexbox* dari Bootstrap 5.
- Navigasi antar halaman menggunakan tautan bergaya tombol (*button link*).

## 🛠️ Teknologi yang Digunakan
- HTML5
- Bootstrap 5 (CDN)
